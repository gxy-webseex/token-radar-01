A token launch radar: ranks 198 pre-token DeFi protocols by implied value, calibrated at run time from 128 live-token comparables in DefiLlama's 2026-11-14 snapshot, with a sortable dashboard, per-protocol factor breakdowns and concrete farm plans. The watchlist (40 protocols, TVL ≥ $50M with no token on record) is fully covered, plus 138 early sub-$50M protocols the radar adds below the floor. Implied value is TVL times a category multiple calibrated from the comparables, adjusted for 7-day growth, time without a token and chain breadth — never a hardcoded list of names.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input input/snapshot.json
```
